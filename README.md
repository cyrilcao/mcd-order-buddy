# 🍔 麦麦点餐搭子（McDonald's Order Buddy）

> 基于 **麦当劳中国 MCP**，**以"营养达标"为核心**的一站式点餐助手。
> 一句需求 = **营养达标 + 价格最优 + 券自动叠加 + 积分到期提醒 + 一键下单**，串联约 8 个官方 Tool。
> 健身控卡、增肌高蛋白、控糖控钠、精打细算、积分党、懒人打工人——一句话全搞定。

---

## ✨ 它能做什么

- **营养达标（核心）**：在您设定的热量 / 蛋白 / 钠 / 糖约束内搭餐，把"想吃麦当劳但怕不健康"变成可量化方案。
- **价格最优**：在可行组合里自动挑最便宜的。
- **券自动叠加**：联动门店券 / 麦麦省券，算出优惠后价，告诉你省了多少。
- **积分到期提醒**：下单前提示"即将过期积分"，建议顺手去麦麦商城兑换或抽奖（融合积分理财思路）。
- **套餐替换建议**：用 `query-meal-detail` 把薯条换玉米杯、含糖饮换无糖，降热量又降钠。
- **一键下单**：您确认后调用 `create-order` 生成订单与支付链接——不默认代下单，安全可控。

> 所有餐品、价格、供应、积分均以 **麦当劳官方 MCP 实时返回** 为准；本助手只做"决策辅助 + 受控执行"。

## 🖼️ 使用示例

**你：** 帮我点份午餐，热量别超 550、蛋白尽量高、用券最划算，顺便看看我快过期的积分，合适就直接下单。

**麦麦点餐搭子：**
```
🍔 麦麦点餐搭子 · 控卡+高蛋白 · 午餐
———————————————
方案A（推荐）：板烧鸡腿堡（去酱） + 玉米杯 + 无糖可乐
  能量 470 kcal | 蛋白 31 g | 脂肪 14 g | 碳水 52 g | 钠 980 mg
  原价 ¥32 → 优惠后 ¥27（省 ¥5，用了门店优惠券）
💡 积分提醒：你有 1,200 积分将于 10-15 到期，可顺手去麦麦商城兑换或抽奖
💡 小贴士：把薯条换玉米杯，同时降热量和钠，饱腹感也不差。
⚠️ 仅供参考，以麦当劳实时信息为准；特殊饮食请遵医嘱。
———————————————
如确认，回复"下单"即可一键生成订单与支付链接。
```

## 🚀 安装与使用

### 方式一：在 WorkBuddy 中使用（推荐，可参与官方联动奖励）

1. 申请麦当劳 MCP Token：登录 https://open.mcd.cn/mcp → 控制台 → 激活 → 复制 Token。
2. 在 WorkBuddy 左侧【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】，粘贴 `mcp-config.example.json` 内容并把 `${MCD_MCP_TOKEN}` 换成你的 Token，保存并启用。
3. 把本仓库的 `SKILL.md` 放入 WorkBuddy 技能目录（如 `~/.workbuddy/skills/mcd-order-buddy/SKILL.md`），或直接在对话中加载本技能。
4. 在对话框输入需求，如「帮我点份控卡午餐，用券最划算，直接下单」，Agent 会自动串联麦当劳 MCP 工具完成推荐与下单。

### 方式二：在其他支持 MCP 的客户端

参考 `mcp-config.example.json`，在 Cherry Studio / Cursor / Trae / VSCode 等客户端配置 `mcd-mcp`（Streamable HTTP，地址 `https://mcp.mcd.cn`，请求头带 `Authorization: Bearer <TOKEN>`），即可让任意支持 MCP 的 Agent 调用本技能逻辑。

## 🧩 技术架构

- **数据层**：麦当劳中国 MCP（`mcd-mcp`）提供的 30+ Tools。
- **编排层**：本 `SKILL.md` 定义"营养优先 + 价格最优 + 积分提醒 + 受控下单"的决策流程，由 Agent 串联。
- **核心 Tool 链（约 8 个）**：`now-time-info` → `query-meals` → `list-nutrition-foods` → `query-meal-detail` → `query-store-coupons`/`available-coupons` → `calculate-price` → `query-my-account` → `create-order`。
- 详见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md)。
